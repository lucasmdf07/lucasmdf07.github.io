The Weather Site

The Weather Site is an early front-end project that combines location information, weather conditions, and layouts for different screen sizes.

Type
Learning project
Tools
HTML, CSS, JavaScript
Focus
Responsive front-end development
Status
Archived build
01

The idea

Weather is a familiar problem with a useful design challenge: people want the important information quickly. The interface needs to put location and conditions in an order that makes sense.

02

What I worked with

The original project includes current-location functionality, city pages, weather imagery, and responsive layouts. It gave me practice connecting page structure, styling, and JavaScript behavior.

03

An archived learning project

I’ve kept the original files available as part of my development history. The city page provides a look at the layout; historical weather values are not a current forecast. Older location or data integrations may no longer be available.
