Client project / Mobile development

Driving for Dollars

Driving for Dollars was a paid React Native project for a real estate startup. The idea was to make a property scouting workflow easier to manage from a phone.

My role
React Native developer
When
2021
Tools
React Native, Firebase, Google Maps
Type
Paid client project
01

The problem

When you’re looking for off-market properties, the drive is only the first step. You also need to remember where you went, save promising properties, and keep the leads organized for follow-up. Those steps need to stay connected.

02

What I worked on

I worked with the startup founder to turn that workflow into a mobile app. The project brought together property pins, route tracking, and lead organization. React Native provided the mobile interface, Google Maps supported the map experience, and Firebase supported the app’s data.

03

The property scouting workflow

A route gives context to the search. A pin makes a property easy to find again. A saved lead keeps the information from disappearing after the drive. The point was to support that whole sequence in one place.

04

What I learned

This was a chance to work directly with a founder and translate a practical business process into software. It pushed me to think about the steps someone follows in the field, rather than treating the app as a collection of separate screens.
