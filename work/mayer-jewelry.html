Mayer Jewelry

Mayer Jewelry is one of my early web projects. It brings together a product catalog, category navigation, promotional imagery, and a storefront layout.

Type
Learning project
Tools
HTML, CSS, Bootstrap
Focus
Storefront layout
Status
Archived build
01

What I was building

The project explores the structure of an online store: a page that helps visitors browse products, understand categories, and move between featured items and collections.

02

Features and layout

The original site includes product photography, category sections, featured items, and a Bootstrap-based layout. Working with those pieces was practice in hierarchy, spacing, and keeping a page readable as the screen size changes.

03

Project background

It’s an early project, and it looks like one. I’m keeping it in the portfolio because it shows where I started and the kinds of interfaces I practiced building. It is a storefront demonstration, not a live retail business.
