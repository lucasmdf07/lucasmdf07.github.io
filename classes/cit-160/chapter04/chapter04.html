Review Questions

1. What is the HTML tag that begins a section of JavaScript code? Include the surrounding less than (<) and greater than (>) symbols in your answer.

  • Answer: <script>

2. What is the JavaScript keyword to declare a variable?

  • Answer: var

3. What does the document.getElementById function do?

  • convert text to a number
  • convert a number to text
  • display a message in a pop-up window and get input from a user
  • find an element within an HTML document

4. What is the symbol that causes the computer to perform string concatenation?

  • Answer: +

5. Write the HTML tag that makes a text field that can be used by this JavaScript statement:
var addr = document.getElementById('address').value;

  • Answer: <input id='address'>

6. Write the opening HTML tag to put a button in an HTML document. Include the surrounding less than (<) and greater than (>) symbols in your answer.

  • Answer: <button>

7. What is the attribute of a button that contains JavaScript code that will be executed when a user clicks on that button?

  • Answer: onClick

8. Write the opening HTML tag that makes a div that can be used by this JavaScript statement:
document.getElementById('output').innerHTML = heartRate;
Include the surrounding less than (<) and greater than (>) symbols and necessary attributes in your answer.

  • Answer: <div id='output'>
