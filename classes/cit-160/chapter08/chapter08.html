Review Questions

1. Given the following JavaScript code, how many times will the computer display the word "Flowers"?

    for (var i = 3; i < 7; i++) {
        alert("Flowers");
      }
    Answer: 4

2. Given the following JavaScript code, how many times will the computer display the word "Apple"?

    var i = 0, limit = 5;
    while (i < limit) {
        alert("Apple");
        i += 2;
      }
    Answer: 3

3. Given the following JavaScript code, how many times will the computer display the word "Goodbye"?

    for (var i = 0; i > 3; i++) {
        alert("Goodbye");
      }
    Answer: 0

4. After the following code executes, what value will the variable result hold?

    var i = 0;
    while (i < 3) {
        alert("Snow");
      }
    Answer: Infinite

1. Write a defining table and a program that asks the user for an integer n and then outputs the sum of all the odd integers between 1 and n, inclusive. For example, if a user entered 10, your program would add 1 + 3 + 5 + 7 + 9 and output 25. If a user entered 11, your program would add 1 + 3 + 5 + 7 + 9 + 11 and output 36.

Enter an Integer Number

      function sumOfOdds(){

      var number = parseInt(document.getElementById('n').value);

          sum += i;

3. Write a defining table and a program to print all powers of 2 from 20 up to 231, inclusive. In other words, your program should output this series: 1, 2, 4, 8, … 2147483648

Defining table

..........................................................................................................................
<!DOCTYPE html>
<html lang="en">
<head>
<meta charset="UTF-8">
<title>My First Program</title>

    <script>
      function definingTable(){

        var output = "";

        for(var i = 0; i < 32; i++){

        output += Math.pow(2, i);
        if(i!=31){
          output += ", "
        }
        }

      document.getElementById('output').innerHTML = output;
      }
    </script>
</head>

<body>
    <div>
    <div id="output"></div>
    <button type='button' onClick='definingTable()'>Defining table</button>
    </div>
