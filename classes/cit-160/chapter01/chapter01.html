3. Computer memory that is volatile must have electricity in order to store data. When electricity is turned off, volatile memory loses its data. Non-volatile memory stores data after electricity is turned off. Which of the following computer memory devices are volatile? (Mark all that apply.)

  • a. cache
  • b. main memory
  • c. flash memory
  • d. hard drive
  • e. DVD

  • a. ASCII

9. Match the kinds of semiconductors

Diode (4) 1. Stores electricity temporarily, somewhat like a miniature battery
Resistor (6) 2. A circuit of transistors, resistors, and capacitors, constructed on a single silicon wafer; sometimes called a chip
LED (5) 3. Two inputs and one output (drain); acts as an automated switch or amplifier with the small current input controlling the large current input and output
Integrated Circuit (2) 4. Allows electricity to flow in only one direction
Capacitor (1) 5. Light emitting diode; emits light when electricity is flowing through it
Transistor (3) 6. Resists the flow of electricity
