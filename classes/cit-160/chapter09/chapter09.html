1. Write a defining table and a program that asks the user for an integer n and then outputs the sum of all the odd integers between 1 and n, inclusive. For example, if a user entered 10, your program would add 1 + 3 + 5 + 7 + 9 and output 25. If a user entered 11, your program would add 1 + 3 + 5 + 7 + 9 + 11 and output 36.

Enter an Integer Number


..........................................................................................................................
<!DOCTYPE html>
<html lang="en">
<head>
<meta charset="UTF-8">
<title>My First Program
    <script>
      function sumOfOdds(){

      var sum = 0;

      var number = parseInt(document.getElementById('n').value);

      for(var i = 0; i <= number; i++){
        if (i%2 != 0)
          sum += i;
        //document.write(sum + " ");
        }

      document.getElementById('output').innerHTML = sum;
      }
    </script>
</head>

<body>
    <div>
      <h2>Enter an Integer Number

      <input type='text' id='n'>
      <div id="output"></div>
      <button type='button' onClick='sumOfOdds()'>Sum of Odds</button>
    </div>
</body>

3. Write a defining table and a program to print all powers of 2 from 20 up to 231, inclusive. In other words, your program should output this series: 1, 2, 4, 8, … 2147483648

Defining table

..........................................................................................................................
<!DOCTYPE html>
<html lang="en">
<head>
<meta charset="UTF-8">
<title>My First Program</title>

    <script>
      function definingTable(){

        var output = "";

        for(var i = 0; i < 32; i++){

        output += Math.pow(2, i);
        if(i!=31){
          output += ", "
        }
        }

      document.getElementById('output').innerHTML = output;
      }
