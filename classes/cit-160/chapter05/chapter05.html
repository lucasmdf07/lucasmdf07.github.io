Review Questions

1. Declare two variables named balance and rate

  • Answer: var balance, rate;

2. Declare a variable named inventor and assign the text "Franklin" to it.

  • Answer: var inventor = "Franklin";

3. What does the document.getElementById function do?

  • prompt the user for input
  • convert a number to text
  • store a value in a variable
  • reserve space in the computer's memory for a variable

4. What does the parseInt function do?

  • display a message in a pop-up window
  • convert an integer to text
  • convert text to an integer
  • display a message in a pop-up window and get input from a user

5. What does the parseFloat function do?

  • convert a number to text
  • display a message in a pop-up window
  • convert text to a number
  • display a message in a pop-up window and get input from a user
