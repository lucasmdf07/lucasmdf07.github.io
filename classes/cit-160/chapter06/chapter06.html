1. The following if statement contains an error. Rewrite it so that it is correct. Assume the variable age already exists and holds a valid number.

  • if age < 8 {
  • Answer: if (age < 8) {

2. The following if statement contains an error. Rewrite it so that it is correct. Assume the variable age already exists and holds a valid number.

  • if (age = 21) {
  • Answer: if (age == 21) {

3. The following if statement contains an error. Rewrite it so that it is correct. Assume the variable age already exists and holds a valid number.

  • if (age >= 30); {
  • Answer: if (age >= 30) {

4. The following if statement contains an error. Rewrite it so that it is correct. Assume the variable age already exists and holds a valid number.

  • if (age =< 55) { {
  • Answer: if (age <= 55) {

5. Write an if statement to determine if the value in the variable age is greater than 12.

  • Answer: if (age > 12) {

6. Write an if statement to check if the value in the variable x is not equal to the value in the variable y.

  • Answer: if (x != y) {
